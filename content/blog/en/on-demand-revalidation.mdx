## Why a timer is not always enough

A `revalidate: 60` works fine as long as your data changes on a predictable
schedule. But if a user edits a record and expects to see it updated right away,
waiting for the next interval is not an option.

```ts title="app/actions.ts"
"use server";
import { revalidateTag } from "next/cache";

export async function updatePost(id: string) {
  await db.post.update(id);
  revalidateTag(`post-${id}`);
}
```

## Path or tag: how to choose

`revalidatePath` clears everything that depends on a route, while a `fetch` tag
is more surgical: it only clears the data you explicitly marked, even when that
data is reused across several different pages.
