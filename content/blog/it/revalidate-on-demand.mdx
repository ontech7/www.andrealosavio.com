## Perche revalidate a tempo non basta

Un `revalidate: 60` va bene finche i tuoi dati cambiano a intervalli
prevedibili. Ma se un utente modifica un record e si aspetta di vederlo subito
aggiornato, aspettare il prossimo intervallo non e un'opzione.

```ts title="app/actions.ts"
"use server";
import { revalidateTag } from "next/cache";

export async function updatePost(id: string) {
  await db.post.update(id);
  revalidateTag(`post-${id}`);
}
```

## Path o tag: come scegliere

`revalidatePath` invalida tutto quello che dipende da una route, `tag` per
`fetch` e piu chirurgico: invalida solo i dati che hai marcato esplicitamente,
anche se sono usati in piu pagine diverse.
